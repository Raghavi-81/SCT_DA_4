# SCT_DA_4
# Task 04 - Business Insights Report (EDA)

## Objective
Perform Exploratory Data Analysis (EDA) on the Superstore Sales Dataset to identify sales trends and business opportunities.

## Dataset
- Records: 9800
- Columns: 18

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab

## Analysis Performed
- Data Cleaning
- Missing Value Analysis
- Duplicate Check
- Category-wise Sales Analysis
- Region-wise Sales Analysis
- State-wise Sales Analysis
- Monthly Sales Trend Analysis
- Top Product Analysis

## Key Insights
- Technology generated the highest sales.
- West region achieved the highest revenue.
- California was the top-performing state.
- Sales showed seasonal fluctuations.
- A small number of products generated a significant share of revenue.

## Conclusion
The analysis identified high-performing categories, regions, and products that can help businesses make data-driven decisions.
